# 音乐文件

本目录用于暂存准备复制到 SD 卡的音频文件。这些文件不会编译进固件。

## 文件信息

| 原文件名 | 格式 | 时长 | 大小 | SHA-256 |
| --- | --- | ---: | ---: | --- |
| `最美的期待.WAV` | PCM、双声道、16 kHz、16 bit | 03:30.867 | 13,495,512 字节 | `AF0F557EE36F23EC1A6B22709992C889318DFC2E0565982955A024321F06EFE9` |
| `风起天阑.WAV` | PCM、双声道、16 kHz、16 bit | 05:28.067 | 20,996,312 字节 | `8CDDAA31ED97801FB262D4E9F76D7E3F13F80CA15EB2FFBCFD33EB738DBF4B13` |

两个文件均为未压缩 WAV，数据速率为 64,000 字节/秒，文件长度及音频帧
对齐检查正常。转换过程先使用 193 抽头 Blackman 窗低通 FIR 抑制 8 kHz
以上频率，再执行 48 kHz 到 16 kHz 的 3:1 降采样，不是简单地每隔三个
采样点取一个，因此不会把原音频的高频分量混叠到 0~8 kHz 频带。

## 复制到 SD 卡

在 SD 卡根目录创建 `music` 文件夹，然后把 WAV 文件复制进去：

```text
/sdcard/music/最美的期待.WAV
/sdcard/music/风起天阑.WAV
```

当前工程已经启用以下配置，可以通过 UTF-8 中文长文件名访问 SD 卡：

```ini
CONFIG_FATFS_LFN_HEAP=y
CONFIG_FATFS_API_ENCODING_UTF_8=y
```

## 播放代码注意事项

这两个 WAV 当前使用标准 44 字节 PCM 文件头，`fmt ` 数据块长度为 16 字节，
音频数据从文件偏移 44 字节开始。播放器仍按 RIFF 数据块结构查找 `data`，
不依赖固定偏移，因此也能正确拒绝或解析带有额外元数据块的文件。

当前播放器仅接受 PCM、双声道、16 kHz、16 bit WAV；播放、录音和语音识别
共用固定 16 kHz I2S 时钟。测试页面左上角的“音乐”按钮会在点击时创建音乐
页面并扫描 `/sdcard/music`；关闭页面时会停止播放并销毁页面。
